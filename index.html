How results are generated & import guide

No ChatGPT API is connected. All analysis runs locally in JavaScript. Coding habits use source-text checks. Algorithm suggestions match a small set of known code patterns. Practice signals use submission verdicts and topic tags. No model reads your code, and no code is sent to an AI provider.

Import a JSON array, or an object with a submissions array. Required per entry: id, timestamp, title, status. Timestamp: ISO date or Unix seconds/milliseconds. Optional: titleSlug, lang, code, topics (array of strings), difficulty. Only the selected trailing calendar year is analyzed. Duplicate IDs are removed. Invalid entries are counted and skipped.

Download the local exporter script and run it while signed in to LeetCode, or prepare JSON from your own archive. A username alone cannot provide a complete code history. Source code is never executed or uploaded. Synced data is stored locally in this extension until you clear it. Manually imported data stays in memory. Downloads contain your code and findings.

Reviews cover formatting, naming, structure, and a small set of algorithm patterns. These are transparent text heuristics, not an AI or AST-based code review. Style findings are suggestions. Algorithm recommendations require checking problem constraints; this app does not prove correctness, complexity, or optimality. The latest source per problem/language is reviewed to avoid counting retries as separate habits. Verdicts suggest investigation, not root causes. Python supports indentation, assignment spacing, naming consistency, function size, queue and Two Sum checks. Python, JavaScript, TypeScript, Java, C++ and C# receive basic generic naming and line-length checks. Missing code or topics limits findings. Accepted submissions alone cannot reveal failed attempts. Imported coverage does not prove your history is complete.
